Core Architecture

Secure Authentication

Robust JWT-based authentication with Argon2 hashing and role-based access control protecting all routes.

Server-Side Evaluation

Answers are scored strictly on the backend. No correct answers or weights are ever leaked to the client.

Anti-Malpractice Detection

Continuous monitoring for tab switches, fullscreen exits, copying, and network drops to ensure integrity.

Risk Analysis

Algorithmic risk scoring aggregates infractions into LOW, MEDIUM, or HIGH risk categories for examiner review.

Audit Logging

Comprehensive tracking of system events, logins, and exam modifications for complete compliance.

Role-Based Access

Strictly separated portals for Students, Examiners, and Administrators to enforce least-privilege principles.

Security by Design

Unlike traditional assessment platforms, SecureAssess assumes the frontend environment is inherently untrusted.

  • Layer 1: Edge Validation Pydantic schemas sanitize all inputs before processing.
  • Layer 2: Identity & Access Stateless JWTs map to database-enforced RBAC rules.
  • Layer 3: Transactional Integrity Atomic MongoDB updates prevent double submissions.
  • Layer 4: Data Obfuscation Correct answers are stripped from API payloads before reaching the student.
